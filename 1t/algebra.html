Algebra

Her finner du 50 oppgaver i algebra for 1T. Prøv å løse hver oppgave før du åpner svaret.

Del 1 – Forenkling av uttrykk

Oppgave 1

Forenkle uttrykket: 3x + 5x.

Svar
3x + 5x = 8x.

Oppgave 2

Forenkle uttrykket: 7a - 2a + 4a.

Svar
7a - 2a + 4a = 9a.

Oppgave 3

Forenkle uttrykket: 4x + 3 - 2x + 7.

Svar
4x - 2x + 3 + 7 = 2x + 10.

Oppgave 4

Forenkle uttrykket: 6y - 3 + 2y - 8.

Svar
6y + 2y - 3 - 8 = 8y - 11.

Oppgave 5

Forenkle uttrykket: 5a + 2b - 3a + 4b.

Svar
5a - 3a + 2b + 4b = 2a + 6b.

Oppgave 6

Forenkle uttrykket: 9x - 4x + 2x - x.

Svar
9x - 4x + 2x - x = 6x.

Oppgave 7

Forenkle uttrykket: 3a + 2b - a + 5b - 4a.

Svar
3a - a - 4a + 2b + 5b = -2a + 7b.

Oppgave 8

Forenkle uttrykket: 12x - 3(2x + 1).

Svar
12x - 6x - 3 = 6x - 3.

Oppgave 9

Forenkle uttrykket: 4(2x - 3) + 5x.

Svar
8x - 12 + 5x = 13x - 12.

Oppgave 10

Forenkle uttrykket: 2(3a + 4) - 3(a - 2).

Svar
6a + 8 - 3a + 6 = 3a + 14.

Oppgave 22

Svar
a⁷ / a³ = a⁴.

Oppgave 23

Forenkle: (x³)².

x² - 16.

Oppgave 27

Oppgave 28

Oppgave 29

Forenkle: (x² + 3x) / x, der x ≠ 0.

Del 4 – Faktorisering og brøkuttrykk

Oppgave 31

Faktoriser: 6x + 12.

Svar
6x + 12 = 6(x + 2).

Oppgave 32

Faktoriser: x² + 5x.

Svar
x² + 5x = x(x + 5).

Oppgave 33

Faktoriser: x² - 9.

Svar
x² - 9 = (x - 3)(x + 3).

Oppgave 34

Faktoriser: x² + 7x + 12.

Svar
x² + 7x + 12 = (x + 3)(x + 4).

Oppgave 35

Faktoriser: x² - 5x + 6.

Svar
x² - 5x + 6 = (x - 2)(x - 3).

Oppgave 36

Forenkle: 2/x + 3/x, der x ≠ 0.

Svar
2/x + 3/x = 5/x.

Oppgave 37

Forenkle: 1/x + 1/(2x), der x ≠ 0.

Svar
1/x + 1/(2x) = 2/(2x) + 1/(2x) = 3/(2x).

Oppgave 38

Forenkle: (x² - 4)/(x - 2), der x ≠ 2.

Svar
x² - 4 = (x - 2)(x + 2). Dermed blir uttrykket x + 2.

Oppgave 39

Forenkle: (x² + 3x)/(x + 3), der x ≠ -3.

Svar
x² + 3x = x(x + 3). Dermed blir uttrykket x.

Oppgave 40

Forenkle: (x² - 16)/(x + 4), der x ≠ -4.

Svar
x² - 16 = (x - 4)(x + 4). Dermed blir uttrykket x - 4.

Del 5 – Likninger og algebraiske problemer

Oppgave 41

Løs likningen: 3x + 5 = 20.

Svar
3x = 15
x = 5.

Oppgave 42

Løs likningen: 5x - 7 = 2x + 8.

Svar
3x = 15
x = 5.

Oppgave 43

Løs likningen: 2(x + 3) = 18.

Svar
2x + 6 = 18
2x = 12
x = 6.

Oppgave 44

Løs likningen: 4(x - 2) = 2x + 6.

Svar
4x - 8 = 2x + 6
2x = 14
x = 7.

Oppgave 45

Løs likningen: (x + 2)/3 = 5.

Svar
x + 2 = 15
x = 13.

Oppgave 46

Løs likningen: x² = 49.

Svar
x = 7 eller x = -7.

Oppgave 47

Løs likningen: x² - 5x + 6 = 0.

Svar
(x - 2)(x - 3) = 0.
x = 2 eller x = 3.

Oppgave 48

Løs likningen: x² - 16 = 0.

Svar
x² = 16
x = 4 eller x = -4.

Oppgave 49

En taxi koster 80 kr i startpris og 15 kr per kilometer. Lag et uttrykk for prisen P når du kjører x kilometer.

Svar
Startprisen er 80 kr, og hver kilometer koster 15 kr.
P(x) = 80 + 15x.

Oppgave 50

En rektangulær hage har lengde x + 4 meter og bredde x meter. Sett opp et forenklet uttrykk for arealet.

Svar
Areal = lengde · bredde.
A(x) = x(x + 4) = x² + 4x m².
