Oppgave 1

Løs likningssystemet:

x² + y² = 2
x² + y = 0
Vis løsning

Vi har:

x² + y² = 2 (1)

x² + y = 0 (2)

Fra (2) får vi:

x² = −y

Setter inn i (1):

−y + y² = 2

y² − y − 2 = 0

(y − 2)(y + 1) = 0

Dermed får vi:

y = 2 eller y = −1

Vi finner x:

Når y = 2: x² = −2 (ingen reelle løsninger).

Når y = −1: x² = 1, som gir x = ±1.

Svar: (x, y) = (1, −1) eller (−1, −1).

Oppgave 2

Løs likningssystemet:

x + y² = 1
x + y = −1
Vis løsning

Fra den andre likningen får vi:

x = −1 − y

Setter inn i den første:

−1 − y + y² = 1

y² − y − 2 = 0

(y − 2)(y + 1) = 0

Dermed får vi:

y = 2 eller y = −1

Vi finner x:

Når y = 2: x = −3.

Når y = −1: x = 0.

Svar: (x, y) = (−3, 2) eller (0, −1).

Oppgave 3

Løs likningssystemet:

3xy − y² = 8
−3x + 5y = 4
Vis løsning

Fra den andre likningen får vi:

−3x = 4 − 5y

x = (5y − 4)/3

Setter inn i den første:

3 · ((5y − 4)/3) · y − y² = 8

5y² − 4y − y² = 8

4y² − 4y − 8 = 0

Dividerer med 4:

y² − y − 2 = 0

(y − 2)(y + 1) = 0

Dermed får vi:

y = 2 eller y = −1

Vi finner x:

Når y = 2: x = 2.

Når y = −1: x = −3.

Svar: (x, y) = (2, 2) eller (−3, −1).

Oppgave 4

Løs likningssystemet:

x² + y² = 10
x + y = 4
Vis løsning

Fra den andre likningen får vi:

y = 4 − x

Setter inn i den første:

x² + (4 − x)² = 10

x² + 16 − 8x + x² = 10

2x² − 8x + 6 = 0

Dividerer med 2:

x² − 4x + 3 = 0

(x − 1)(x − 3) = 0

Dermed får vi:

x = 1 eller x = 3

Vi finner y:

Når x = 1: y = 3.

Når x = 3: y = 1.

Svar: (x, y) = (1, 3) eller (3, 1).

Oppgave 5

Løs likningssystemet:

x² + 2x − y = −1
x + y = −2
Vis løsning

Fra den andre likningen får vi:

y = −2 − x

Setter inn i den første:

x² + 2x − (−2 − x) = −1

x² + 2x + 2 + x = −1

x² + 3x + 3 = 0

Vi bruker diskriminanten:

d = 3² − 4 · 1 · 3

d = 9 − 12 = −3

Siden diskriminanten er negativ, har andregradslikningen ingen reelle løsninger.

Svar: Likningssystemet har ingen reelle løsninger.

Oppgave 6

Løs likningssystemet:

x − y = 1
x² − 2x + y² = 7
Vis løsning

Fra den første likningen får vi:

y = x − 1

Setter inn i den andre:

x² − 2x + (x − 1)² = 7

x² − 2x + x² − 2x + 1 = 7

2x² − 4x − 6 = 0

Dividerer med 2:

x² − 2x − 3 = 0

(x − 3)(x + 1) = 0

Dermed får vi:

x = 3 eller x = −1

Vi finner y:

Når x = 3: y = 2.

Når x = −1: y = −2.

Svar: (x, y) = (3, 2) eller (−1, −2).

Oppgave 7

Løs likningssystemet:

x² − 2x − y = 6
x − y − 2 = 0
Vis løsning

Fra den andre likningen får vi:

y = x − 2

Setter inn i den første:

x² − 2x − (x − 2) = 6

x² − 3x + 2 = 6

x² − 3x − 4 = 0

(x − 4)(x + 1) = 0

Dermed får vi:

x = 4 eller x = −1

Vi finner y:

Når x = 4: y = 2.

Når x = −1: y = −3.

Svar: (x, y) = (4, 2) eller (−1, −3).

Oppgave 8

Løs likningssystemet:

x² + 2x + y = 3
x + y = 1
Vis løsning

Fra den andre likningen får vi:

y = 1 − x

Setter inn i den første:

x² + 2x + 1 − x = 3

x² + x − 2 = 0

Vi faktoriserer:

(x + 2)(x − 1) = 0

Dermed får vi:

x = −2 eller x = 1

Vi finner y ved å bruke y = 1 − x:

Når x = −2:

y = 1 − (−2) = 3

Når x = 1:

y = 1 − 1 = 0

Svar: (x, y) = (−2, 3) eller (1, 0).
